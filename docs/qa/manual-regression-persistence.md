# Prism ToDo 手工回归记录：本地持久化

版本基线：`fbad027`

## 回归项 1：新增任务 -> 重启 -> 仍保留

步骤：
1. 启动 Prism ToDo
2. 在“快速记录”输入一个新任务
3. 点击“记录到收件箱”
4. 关闭应用
5. 重新启动应用

预期：
- 新增任务仍在“收件箱”中

结果：
- 已通过

## 回归项 2：Inbox -> Today -> 重启 -> 仍一致

步骤：
1. 启动 Prism ToDo
2. 选择一条收件箱任务
3. 点击“移到今天”
4. 关闭应用
5. 重新启动应用

预期：
- 该任务仍在“今天”中

结果：
- 已通过

## 回归项 3：标记完成 -> 重启 -> 仍一致

步骤：
1. 启动 Prism ToDo
2. 选择一条任务并勾选完成
3. 关闭应用
4. 重新启动应用

预期：
- 该任务仍保持完成状态

结果：
- 已通过

## 说明

本轮持久化方案为本地 JSON 文件存储，目标是优先保证 Phase 1 桌面原型在重启后的状态连续性。
